# Implementation plan

Decisions from approval: local Supabase (Docker) for dev/tests and demo mode when env is missing; brand constant `Smartmind` in `content/brand.ts`; original "unity" node mark with a drop-in slot for the supplied logo at `public/brand/logo.svg`; English only; site URL `http://localhost:3000` via `NEXT_PUBLIC_SITE_URL`.

Each task is about an hour, ends with a commit. Test commands: `npm run lint`, `npm run typecheck`, `npm test` (Vitest), `npm run e2e` (Playwright).
