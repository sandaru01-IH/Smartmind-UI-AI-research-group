SMARTMIND Logo Pack
===================

Contents
--------
- png/color/icon: Transparent PNG icon-only assets in common app/web sizes.
- png/color/with_wordmark: Transparent PNG full logos with SMARTMIND wordmark.
- png/black/icon: Transparent black icon-only versions.
- png/black/with_wordmark: Transparent black full logos.
- png/white/icon: Transparent white icon-only versions for dark backgrounds.
- png/white/with_wordmark: Transparent white full logos for dark backgrounds.
- ico: Multi-size ICO files.
- favicon.ico: Standard color favicon.

Suggested usage
---------------
- Website header/logo: use png/color/with_wordmark
- Favicon: use favicon.ico or ico/smartmind-favicon-color.ico
- App icon / PWA icon: use png/color/icon/smartmind-color-icon-512x512.png or 1024x1024
- Documents / reports: use the color or black full logo depending on background
- Dark backgrounds: use white versions
