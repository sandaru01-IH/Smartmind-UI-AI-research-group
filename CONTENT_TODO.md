## 4. Technical to-dos before launch

- Apply `supabase/migrations/20261014000000_init.sql` to the hosted project (`npx supabase db push`).
- In the hosted Supabase dashboard, turn **off** "Allow new users to sign up" (the local `config.toml` already does) and set a password policy of 12 or more characters.
- Set the Site URL and redirect URLs to the production domain.
- Replace the in-memory login throttle (`lib/auth/throttle.ts`) with a shared store (for example Upstash) if the site runs on more than one instance. Supabase Auth applies its own rate limits as well.
- Rotate the local demo keys. Never reuse them on a hosted project.
